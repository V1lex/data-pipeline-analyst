# Разговорный интерфейс PA Landing V4

Реализован подтверждённый пользователем макет `frontend/src/workspace-v4/layout/full-page-v2.png`. Диалог занимает основной экран; схема, спецификация, результаты TLC и файлы доступны в одной контекстной панели. Боковая история использует проекты API. Профиль — единственный статичный `user`, без аккаунтов и входа.

`frontend/src/workspace-v4/landing.json` хранит подтверждение, принятые файлы четырёх секций, композицию и фактические переходы. `App.jsx` связывает секции с контроллером `workspace-v4/state.js` и API. React Flow сохранён для просмотра схемы. Историческая версия использует свой снимок, проверку и артефакты; текущий черновик не подставляется вместо отсутствующего контекста старой версии.

Первое сообщение создаёт проект. Ошибка провайдера сохраняет текст и созданный проект для повторной попытки. Подтверждённое сервером сообщение не отправляется повторно после сбоя чтения истории. Генерация доступна после согласования и успешного завершения TLC; неизвестный исход запроса сохраняет UUID для восстановления уже созданного результата.

На мобильном история и контекстная панель открываются модально; доступны Escape, ограничение Tab внутри панели и возврат фокуса. Ошибки действий выводятся внутри открытой панели. Длинные имена файлов переносятся, а reduced motion отключает перемещения.

## Управление диалогами — 02.11.2026

У каждой строки истории доступно меню `⋯`: «Переименовать» открывает встроенную форму, «Удалить» — подтверждение удаления сообщений, версий и файлов. Имя сохраняется в PostgreSQL. Отмена и ошибка сохраняют диалог, а неудачный запрос оставляет форму с доступным сообщением. После удаления выбранного диалога открывается пустой чат; удаление другого сохраняет текущий черновик. Удалённые записи и переименования защищены от поздних ответов загрузки истории.

У composer убраны вложенный прямоугольный outline textarea и двойной внешний контур: остаётся одна скруглённая граница фокуса. У строк истории клавиатурный контур расположен внутри скругления и не обрезается.

Проверки: 220 backend passed / 7 skipped, 16 frontend unit passed, 6 browser scenarios passed; production build и Ruff прошли. Независимое ревью не нашло Critical/Important; найденная Minor-гонка заголовка исправлена с RED→GREEN тестом. Docker останавливается из корня командой `docker compose --env-file .env -f infra/docker-compose.yml down`; локальные процессы вне Docker — отдельно через Ctrl+C.
