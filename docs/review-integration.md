## Исправленные блокирующие проблемы

- Разные структуры и глобальные `src.*` импорты: единые пакеты под backend/src; проверена установка wheel вне исходной папки.
- Несовместимые DB-статусы, отсутствие server defaults, снимка требований/полного вердикта и generation_manifest: совместимая миграция поверх оригинальной Alembic-ревизии. Один владелец схемы.
- TLC parser выдавал PROPERTY_HOLDS по одному прогресс-сообщению, а reachable пропускался: явное завершение и агрегация всех проверок; неизвестные ошибки блокируют генерацию.
- Глобальные файлы compiler могли смешать параллельные задания: отдельная временная папка на запуск.
- Незавершённая семантическая валидация, неполный initial, неизвестные переменные и ошибочные домены: структурированные ошибки; TypeOK и безопасное кодирование строк.
- Диалог терял структурированные параметры, повторные операции и состояние после перезапуска: snapshots, типизированные parameter_updates, устойчивые ID/редакции, canonical readiness и откат неудачного хода.
- Аналитик выдумывал source/sink defaults и guard data_valid: слепая автоправка удалена; formal repair требует явный валидный patch.
- Builder мог переписать согласованные значения или сохранить результат после истечения lease: сравнение нормализованного снимка и атомарная проверка lease перед INSERT.
- Гонка ленивой инициализации создавала два Gemini-клиента: общий lock; кэшированная выдача генерации не требует доступного провайдера.
- Frontend не позволял выйти из сохранённой FAILED-попытки, смешивал старую версию с новым черновиком и допускал коллизии sink ID в React Flow: исправлены обработка UUID/ошибок, привязка версии и namespace узлов.
- В черновом Compose отсутствовали Dockerfiles, worker/frontend и рабочая точка входа: добавлены реализации, healthchecks, общий build context и startup dependencies.

## Проверено

216 тестов проходят с реальными временными схемами PostgreSQL и Java/TLC; 7 пропущены (6 отдельных Spark-примеров и live Gemini test). Проверены HTTP-сценарий, отрицательные исходы TLC, достижимость, timeout, idempotent replay после перезапуска, lease race и неизменяемость версий.

Ruff, production build frontend и `docker compose config --quiet` проходят. Установленный wheel импортирует все модули и применяет Alembic вне checkout. Проверка браузером: создание проекта, отображение графа синтетического примера, результат настоящего TLC, адаптивная раскладка. Полный Docker startup не проверен: daemon выключен.

Один реальный вызов Gemini вернул HTTP 400, ограничение региона. Успешная LLM-генерация и выполнение именно этого кода не заявляются; по указанию пользователя доступность модели не блокировала интеграцию.
