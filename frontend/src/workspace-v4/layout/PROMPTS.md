# Full-page layout v1

Статус: подготовка макета; согласование пользователя ещё не получено. Тексты и действия заданы в landing.json.

## Композиция v1
Тёмный sidebar проектов; тёплый светлый canvas; синие основные действия и мятные статусы. Верхняя панель проекта и 4 этапа, чат слева, DAG справа, результат TLC и артефакты ниже. Пример — выручка по городам. Все демонстрационные значения служат только референсом компоновки; в реализации данные берутся из текущего API. Код и диаграмма реализуются отдельными компонентами, а не картинкой.

## Макет v1 отклонён пользователем
Обратная связь: слишком «иишно», лишние цифры и тексты MVP; диалог должен быть в основе, артефакты и другую информацию открывать по запросу. Референс направления — ChatGPT, Claude, DeepSeek.

## Макет v2
Разговорный интерфейс: тихий sidebar истории, центральный чат, composer снизу, вспомогательные сведения в контекстной выезжающей панели. Без dashboard-метрик, номеров этапов, служебных бейджей и маркетингового текста. Точная постановка генерации: IMAGEGEN_PROMPT_V2.txt.
