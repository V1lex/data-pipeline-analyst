- Статус: OPEN
- Дата: 2026-10-30
- Область: storage / integration
- Симптом: схема БД существует как изображение; моделей, миграций, backend и LLM-клиента в доступных ветках нет.
- Как воспроизвести: проверить `git ls-files`, `git ls-tree -r --name-only feature/storage` и список веток origin.
- Ожидание: использовать действующие общие контракты, не дублируя работу участников.

- Исправление: код не менялся; вопросы границ хранения и контракта зафиксированы в `architecture.md` и переданы пользователю.
- Проверка: исследованы GitHub refs и актуальный `origin/tla_tlc` на `77eba11`.
- Ограничения: готовность кода вне доступного репозитория не проверена. Можно готовить независимую часть через согласованный интерфейс.

- Дата: 2026-10-30
